## 🚀 Быстрый старт

### 1. Клонирование репозитория

```bash
git clone https://github.com/your_username/data-science-full-course.git
cd data-science-full-course
```

### 2. Создание виртуального окружения

```bash
# Windows
python -m venv venv
venv\Scripts\activate

# macOS / Linux
python3 -m venv venv
source venv/bin/activate
```

### 3. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 4. Запуск Jupyter Notebook

```bash
jupyter notebook
```

После запуска откройте в браузере `http://localhost:8888/` и перейдите в папку `part_1_theory/`.

## 📚 Содержание курса

### 🧩 Часть 1. Теория и инструменты

> **Часть 1** — это теоретическая основа курса. В ней представлены фундаментальные методы и подходы Data Science, примеры кода, Jupyter-блокноты и визуализации.

Курс состоит из **12 разделов**, каждый из которых подробно раскрывает свою тему:

**Раздел 1. Язык программирования Python**
Основы синтаксиса Python: типы данных, условные операторы, циклы, коллекции, функции, объектно-ориентированное программирование, исключения, файловый ввод-вывод, модули, итераторы, генераторы и декораторы.

**Раздел 2. Инструменты для работы в Data Science**
Обзор и настройка ключевых сред разработки: Visual Studio Code, GigaIDE, Jupyter Notebook, Google Colab. Знакомство с платформой Kaggle для соревнований по машинному обучению.

**Раздел 3. Предобработка и хранение данных**
Работа с библиотеками NumPy и Pandas. Чтение и запись файлов разных форматов (CSV, XLSX, JSON, TXT). Парсинг HTML-страниц, работа с API. Основы работы с базами данных SQLite и системой контроля версий Git.

**Раздел 4. Визуализация данных**
Создание статических и интерактивных графиков с помощью библиотек Matplotlib, Seaborn и Plotly. Виды графиков, правила их оформления и выбора под конкретную задачу.

**Раздел 5. Статистический анализ данных**
Описательная статистика: меры положения, разброса, асимметрии и распределения. Корреляция: Пирсон, Спирмен, Кендалл. Статистические гипотезы, A/A и A/B-тестирование, p-value и доверительные интервалы. Параметрические и непараметрические тесты.

**Раздел 6. Очистка данных и EDA**
Обработка пропущенных значений, удаление и исправление выбросов. Инженерия признаков (Feature Engineering), кодирование категориальных признаков, преобразование признаков (Feature Transformation). Построение и проверка статистических гипотез. Отбор наиболее значимых признаков (Feature Selection).

**Раздел 7. Машинное обучение**
Виды алгоритмов машинного обучения: с учителем, без учителя, с подкреплением. Регрессия, классификация, кластеризация. Метрики оценки качества моделей. Валидация и оптимизация гиперпараметров. Ансамблевые методы: бэггинг, стекинг, бустинг. Пайплайны в машинном обучении.

**Раздел 8. Глубокое обучение**
Модель искусственного нейрона и нейронные сети. Фреймворк PyTorch и тензорное представление данных. Конвейеры для пакетной обработки данных. Свёрточные нейронные сети (CNN), рекуррентные сети (RNN, LSTM, GRU). Трансформеры и генеративно-состязательные сети (GAN).

**Раздел 9. Компьютерное зрение**
Фильтрация и преобразование изображений. Поиск объектов и измерение линейных размеров. Трекинг объектов: MOG2, Meanshift, Camshift. Детекторы признаков: Harris, SIFT, FAST, ORB. Каскадные классификаторы Хаара. Использование предобученных моделей (YOLO, ResNet). Работа с веб-камерой и видеопотоком.

**Раздел 10. Обработка естественного языка (NLP)**
Кодирование данных: One-Hot, TF, TF-IDF, эмбеддинги. Токенизация, лемматизация, стемминг. Перенос обучения (Transfer Learning) и модели BERT, GPT. Распознавание именованных сущностей (NER). Системы вопрос-ответ (QA). Машинный перевод.

**Раздел 11. Работа с базами данных (PostgreSQL)**
Принципы построения реляционных баз данных. Язык структурированных запросов SQL: SELECT, WHERE, JOIN, GROUP BY, подзапросы, CTE. СУБД PostgreSQL и утилита pgAdmin. Клиенты для работы с БД: DBeaver, DbVisualizer. Работа с PostgreSQL из Python.

**Раздел 12. Развёртывание и мониторинг модели**
Реализация ML-алгоритма для задачи классификации. Создание фронтенда и бэкенда веб-приложения. Фреймворки Flask и Django. Контейнеризация с Docker и Docker Hub. Развёртывание на сервере с Ubuntu. Трехуровневая архитектура: Nginx + Gunicorn + Uvicorn.

📖 **Подробнее:** [`part_1_theory/`](./part_1_theory/)

### 🧪 Часть 2. Инженерный практикум

> **Часть 2** — это практическая часть курса. Здесь собрано **более 200 заданий** разного уровня сложности. Решения не предоставляются — студенты должны решать их самостоятельно.

Практикум состоит из **12 тематических блоков**, каждый из которых соответствует разделу теоретической части:

**Блок 1. Практические задания по типам данных** ⭐
Задания на закрепление знаний о базовых типах данных Python. Отработка навыков ввода-вывода, преобразования типов, работы с операторами и срезами строк.

**Блок 2. Инструментарий разработчика Python** ⭐
Практические задания по настройке и работе в средах разработки: VS Code, GigaIDE, Jupyter Notebook, Google Colab, Kaggle.

**Блок 3. Предобработка и хранение данных** ⭐⭐
Работа с NumPy и Pandas, чтение и запись файлов разных форматов, парсинг HTML, API, SQLite, Git.

**Блок 4. Визуализация данных** ⭐⭐
Создание графиков с помощью Matplotlib, Seaborn и Plotly. Выбор типа графика, оформление, стилизация.

**Блок 5. Статистика и проверка гипотез** ⭐⭐⭐
Описательная статистика, корреляция, доверительные интервалы, A/B-тестирование, параметрические и непараметрические тесты.

**Блок 6. Подготовка данных и Feature Engineering** ⭐⭐⭐
Обработка пропусков, выбросы, создание новых признаков, кодирование категорий, масштабирование, PCA, отбор признаков.

**Блок 7. Машинное обучение. Базовые алгоритмы** ⭐⭐⭐⭐
Регрессия, классификация, кластеризация, метрики, валидация, оптимизация, ансамбли, пайплайны.

**Блок 8. Глубокое обучение** ⭐⭐⭐⭐⭐
Нейроны, тензоры, DataLoader, линейная регрессия, CNN, RNN, LSTM, GAN на PyTorch.

**Блок 9. Компьютерное зрение** ⭐⭐⭐⭐
Фильтрация, поиск объектов, трекинг, детекторы признаков, каскады Хаара, YOLO, работа с веб-камерой.

**Блок 10. Обработка естественного языка** ⭐⭐⭐⭐
Кодирование данных, токенизация, перенос обучения, NER, QA, машинный перевод.

**Блок 11. Базы данных и SQL** ⭐⭐⭐⭐
Проектирование БД, SQL-запросы, JOIN, CTE, PostgreSQL, работа с БД из Python.

**Блок 12. Сквозной проект: от идеи до веб-сервиса** ⭐⭐⭐⭐⭐
Полный цикл: EDA → ML-модель → Flask-приложение → Docker → развёртывание.

## 🎓 Как проходить курс

Рекомендуемый порядок изучения:

1. **Изучите теоретический материал** соответствующего раздела.

5. **Переходите к следующему разделу** только после успешного закрепления материала.

- 30% — изучение теории
